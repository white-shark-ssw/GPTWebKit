- **Alpha46 implementation**:
  - Added `Diagnostics/CEConversationIdentityTrace.{h,mm}`. User-started trace persists under Application Support and stores session-active state/session ID in `NSUserDefaults`, so force-close/relaunch continues the same trace with a new launch UUID.
  - Existing `CEBootstrap` starts the trace lifecycle manager; no new constructor or state authority was added.
  - Conversation menu adds `开始会话识别记录`; while active it becomes `结束并导出识别日志`, exporting one `.log` file through `UIDocumentPickerViewController`.
  - `CEEnhancerUI` records menu origin, sanitized configuration/menu identifiers, original menu action/menu tree, source-view class/frame, explicit conversation IDs, catalog-recognized conversation titles, context state and menu candidate IDs/titles/count. Existing menu target resolution behavior remains unchanged.
  - `CENetworkObserver` records sanitized official request method/path/query-key names/status/error plus explicit conversation IDs found in conversation URL/query. For request bodies it parses only in memory and persists only explicit `conversation_id` / `conversationId` values; upload `fromData:` is handled the same way. Share-looking paths are separately tagged `NET-SHARE-*`.
  - Pull/Reload/Export paths log the exact proof/record/target IDs they use. Manual Reload logs its target, route attempt/delivery and verification source without persisting nonce/full route.
  - No Pull/Reload/menu behavior move, floating-UI removal, network identity write, stale-ID fallback, new timer/retry/watchdog/debounce, or second conversation authority was introduced.
- **Trace privacy contract implemented**: never persist Authorization, Cookie, account IDs, raw request templates, full headers, request/response bodies or message contents. Generic accessibility strings are not dumped. Conversation title/ID are persisted only within the explicitly user-started diagnostic session for correlation. Structural identifiers containing non-safe text are redacted unless an explicit conversation ID can be extracted.
